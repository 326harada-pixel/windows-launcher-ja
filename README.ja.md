## このフォークで変えたところ

- UIを全面的に日本語化(辞書と、画面の文字を置き換える仕組み。元は英語だけです)
- スタートメニューの「プログラム」
  - 自分のフォルダを作る、名前を変える、削除する、プログラムを出し入れする
  - 複数選択(フォルダの中でもできます)
  - 種類ごとのフォルダへの自動振り分け
  - 高さが画面を超えるフォルダのメニューは、上下にスライドできます
- ユーザーの画像を、端末の写真から選べる(中央を正方形に切り抜き、256pxに縮小し、アプリの中だけに保存)
- Windows Updateの確認を無効化
- アプリのID(`jp.personal.winlauncher`)を変更し、元のアプリと一緒に入れられる
- ランチャーのアイコンを、Windows 7のスタートボタン風に変更
- 日本語のエクスプローラー画像(XP、98)。元のWindowsの画像をもとにしています

## 使い方

1. Android 10以上の端末が必要です。ビルドして入れてください(下の「ビルド」を参照)。
2. 最初に、ホームアプリとして、このランチャーを選びます。
3. 通知やアクセシビリティなどの特別な権限は、元のREADMEの「Special Permissions」と同じ手順で許可します(`adb install -r` で入れると、制限の確認が出ません)。

## ビルド

JDK 21とAndroid SDKが必要です。

```bash
./gradlew :app:testDebugUnitTest
./gradlew :app:assembleDebug
```

リリース版に署名するには、署名用の設定ファイルを、リポジトリの外に置きます。置かない場合、署名なしのビルドになります。鍵とパスワードは、リポジトリに入れないでください。
